## 수정 1 — 메인 USP 문구

```
[현재] 도쿄민박이 확인한 도쿄 현지 숙소
[수정] 예약 전후를 한국어로 안내하는 도쿄 현지 숙소
       (UI 폭이 좁은 경우) 한국어로 안내받을 수 있는 도쿄 현지 숙소
```

**사용 금지:**
- `위치·체크인 방식·연락 체계를 확인한`
- `확인`, `검수`, `보장` 등 운영상 입증 범위가 필요한 표현

---

## 수정 2 — 숙소 상세 maxGuests 자동 문구

현재 `maxGuests === 2` 숙소에 아래 문구가 남아 있다:

```
[현재] 최대 2명 기준이므로 2~3인 커플·소규모 여행에 맞는지 먼저 확인하세요.
```

`maxGuests` 값에 따라 아래로 정확히 분기한다:

```
maxGuests === 1:
  "최대 1명 기준이므로 1인 여행자에게 적합합니다. 2명 이상인 경우 다른 숙소를 함께 검토해 주세요."

maxGuests === 2:
  "최대 2명 기준이므로 1인 여행자 또는 2인 커플 여행에 적합합니다. 3명 이상인 경우 다른 숙소를 함께 검토해 주세요."

maxGuests >= 3:
  "최대 {maxGuests}명까지 이용 가능한 숙소입니다. 실제 이용 인원과 침대 구성, 공간 활용이 여행 스타일에 맞는지 예약 전 확인해 주세요."
```

**추가 검색 범위:**
자동 생성 SEO 문구, 상세 하단 안내 문구, 추천 대상 문구 템플릿 전체를 검색해서 아래 문자열이 남아 있으면 같이 수정한다:
- `2~3인`
- `2~3인 커플`
- `소규모 3인`
- `3인` (maxGuests 2 이하 숙소 컨텍스트에서만)

## 확인 3 — 숙소 운영 정보 섹션 구조 점검 (코드 변경 없음)

이전 패치에서 추가한 "숙소 운영 정보" 섹션 구조가 실제로 코드에 존재하는지 확인하고 보고한다.

확인할 필드:
- 운영 유형
- 허가·신고번호
- 숙소 운영자
- 한국어 안내
- 후기 출처

**처리 기준:**
- 구조가 있고 데이터 없을 때 섹션이 숨겨지는 상태 → 정상, 보고만 한다
- 구조 자체가 없는 것으로 확인 → **이번 패치에서 추가하지 말고 TODO로 보고**한다. 별도 패치로 분리한다
