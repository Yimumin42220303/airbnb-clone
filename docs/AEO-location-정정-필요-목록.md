# 숙소 location 정정 필요 목록 (어드민 작업용)

배경: AEO(Answer Engine Optimization)는 `Listing.location` 자유 텍스트에서 역명/도보 분/지역명을 정규식으로 추출합니다. 데이터가 보수적으로 처리되도록 설계해, 다음 표현이 명확히 들어 있을 때만 AEO 문구에 사용됩니다.

- **역명 + 도보 N분**: `"○○역 도보 N분"` 또는 `"○○역에서 도보 N분"` (일본어 `"○○駅 徒歩N分"` 도 동일)
- **메이저 지역명**: 화이트리스트 매칭. (예: 신주쿠/시부야/롯폰기/이케부쿠로 등)

표현이 누락되면 의도된 보수 동작으로 H1/title/meta description에서 역명·도보 표현이 빠지고, 검색·AI 노출 효과가 약해집니다. 이 문서의 정정만 어드민 페이지에서 반영하면 코드 변경 없이 즉시 AEO가 풍부해집니다.

> 본 문서는 데이터를 직접 수정하지 않고, 사람이 어드민에서 일일이 확인·수정하기 위한 안내 목적입니다.

## 2. 권장 정정 (1건)

운영자 판단에 따라 더 풍부한 AEO 매칭을 위해 추가 정보를 입력하면 좋은 케이스.

### ④ AsahiStay -Shinjuku2 — 도보권 역 정보 부재

| 항목 | 값 |
|---|---|
| listing id | `cmokrmlmh0001ylbho93tkmxt` |
| 숙소명 | 좋은 위치, 깨끗한 레지덴셜 스테이지, AsahiStay -Shinjuku2 |
| 현재 location | `JR신주쿠역에서 버스 15분 / 나카노구, 도쿄` |
| 권장 location | `(가장 가까운 도보 가능 역)역 도보 N분 / 나카노구, 도쿄 / JR신주쿠역에서 버스 15분` |
| 수정 이유 | "버스 15분"은 도보 거리가 아니므로 AEO에서 의도적으로 walkMinutes를 미출력 중 (보수 동작). 가장 가까운 도보 역을 표기하면 즉시 매칭 가능. |
| 비고 | "버스" 키워드는 AEO 추출 대상이 아니므로 그대로 두어도 무방함. 도보권 역 정보만 추가하면 됨. |
| 정정 후 변화 (예상) | meta description이 "신주쿠 인근에 있는 …" → "(가장 가까운 도보 가능 역)역 도보 N분 거리에 있는 …"로 풍부화. |

## 5. 입력 가이드라인 (앞으로의 등록·수정 시 참고)

신규 숙소를 등록하거나 location을 수정할 때, 아래 형식을 권장합니다.

```text
{구/시}, {도쿄} / {노선} {역명}역 도보 {N}분
```

**예시**

```text
시부야구, 도쿄 / JR 야마노테선 시부야역 도보 5분
신주쿠구, 도쿄 / 도에이 신주쿠선 신주쿠 3초메역 도보 6분
미나토구, 도쿄 / 도에이 오에도선 롯폰기역 도보 4분
```

**핵심 체크리스트**

- [ ] 역명 뒤에 "역" 글자가 들어 있는가? (예: "혼조아즈마바시역")
- [ ] "도보 N분"이 모두 명시되어 있는가? (분 글자 누락 주의)
- [ ] 같은 문구가 중복되지 않았는가?
- [ ] 도보 거리가 아닌 경우(버스/차)는 별도 표기 (예: "/ JR신주쿠역에서 버스 15분")
- [ ] 한 줄에 여러 역을 언급할 경우 가장 가까운 역을 가장 앞에 둘 것

이 가이드라인을 지키면 AEO 자동 생성 결과(H1/title/meta description/JSON-LD)가 자동으로 풍부해집니다.
