# 호스트 모집 마케팅 전략 기획

> **목표 KPI**: 숙소 수 확보(호스트 모집)  
> **타깃**: 일본 도쿄 민박 호스트 (개인·관리대행사)  
> **보틀넥**: ① 모객 효과 의문 ② 미지의 OTA·트러블 불안 ③ 등록·운영 복잡함

---

## 1. 일본 호스트 심리 이해

### 1.1 민박 호스트의 본질적 욕구
- **안정적 수입**: 예약이 꾸준히 들어와야 한다
- **리스크 회피**: 트러블·분쟁·손해를 피하고 싶다
- **수고 최소화**: 이미 에어비앤비·부킹닷컴 등으로 바쁜데, 새 채널 추가는 부담
- **신뢰**: "이 사람/회사가 믿을 만한가"가 결정적

### 1.2 일본 특유의 행동 패턴
- **口コミ(구전) 신뢰**: 다른 호스트·관리대행사의 추천이 강함
- **LINE 선호**: 이메일보다 LINE으로 상담·문의
- **단계적 관계**: 한 번에 등록보다 "일단 상담 → 소규모 시험 → 본격 등록" 선호
- **손해·트러블 회피**: "등록해도 손해 안 보는가"가 최우선

---

## 2. 보틀넥별 해결 전략

### 2.1 보틀넥 ①: 「등록해도 모객에 의미가 있을까?」

**핵심**: "효과가 있다"는 **증거**를 보여주는 것.

| 전략 | 내용 | 우선순위 |
|------|------|----------|
| **실적 숫자 공개** | "등록 호스트 X명, 월 예약 Y건, 평균 체류 Z박" 등 구체적 수치 | 높음 |
| **호스트 사례/인터뷰** | "A호스트님은 등록 2주 만에 첫 예약" 등 짧은 후기 | 높음 |
| **게스트 수요 증명** | "한국인 게스트 문의가 매월 N건, 수용 가능 숙소 부족" | 높음 |
| **시즌·이벤트 연동** | "곧 성수기, 지금 등록하면 노출 기회" | 중간 |
| **무료 시험 등록** | "3개월 무료 등록, 효과 없으면 그만두셔도 됩니다" | 높음 |

**메시지 예시 (일본어)**:
- 「韓国人ゲストの問い合わせが月○○件。受け皿が足りていません」
- 「登録ホスト様の平均、初予約まで○日」
- 「まず3ヶ月無料でお試し。効果がなければそのままおやめください」

---

### 2.2 보틀넥 ②: 「미지의 OTA, 트러블 생기는 거 아닐까?」

**핵심**: **신뢰**와 **리스크 제로화**를 동시에 전달.

| 전략 | 내용 | 우선순위 |
|------|------|----------|
| **운영자 얼굴·실명** | X(Twitter) 개인 계정, LINE 상담 등 "실제 사람"이 대응 | 높음 |
| **호스트 우선 정책 명시** | "一方的な返金は行いません" 등 이미 LP에 있는 문구 강화 | 높음 |
| **탈퇴·중단 자유** | "いつでも掲載停止・退会可能" | 높음 |
| **계약서·약관 요약** | 복잡한 약관 대신 "호스트를 지키는 3가지 원칙" 등 1페이지 요약 | 중간 |
| **기존 호스트 추천** | "○○管理会社様ご紹介" 등 실명·실제 관계 공개 | 높음 |
| **소규모 시험 제안** | "1物件だけまず掲載" | 높음 |

**메시지 예시**:
- 「マイクロOTAだから、顔の見える運営。トラブル時もホスト様の味方です」
- 「掲載停止はいつでも可能。リスクゼロでお試しください」

---

### 2.3 보틀넥 ③: 「등록·운영이 복잡하지 않을까?」

**핵심**: **귀찮음을 제거**하고 **첫 걸음의 허들**을 낮춤.

| 전략 | 내용 | 우선순위 |
|------|------|----------|
| **LINE 우선 플로우** | "등록은 LINE相談から" → 정보 수집 후 **운영진이 대신 입력** 옵션 | 최고 |
| **단계별 등록** | 最小情報(사진·가격·위치)만으로 먼저 게시 → 이후 상세 입력 | 높음 |
| **대리 입력 서비스** | "에어비앤비 링크만 보내주시면 우리가 이전해 드립니다" | 높음 |
| **동영상·스크린샷 가이드** | "5分でできる掲載の流れ" | 중간 |
| **상담 시 예상 시간 명시** | "初回相談は15分程度" | 중간 |

**메시지 예시**:
- 「Airbnbの掲載情報を送っていただければ、こちらのスタッフが転記します」
- 「LINEで住所・写真・料金をお伝えいただくだけでOK。面倒な入力は後回し」

## 3. 채널별 실행 전략

### 3.1 LINE (최우선)
- **역할**: 1차 접점, 상담·신뢰 구축
- **활동**:
  - 자동 응답 + 가능하면 **실시간 사람 응답**
  - "등록 희망" 키워드 시 → 바로 "대리 입력 가능" 안내
  - 주 1~2회, 유용한 정보(예: 한국인 게스트 트렌드) 공유로 관계 유지

### 3.2 X (Twitter)
- **역할**: 브랜드 노출, 실적·사례 공유
- **활동**:
  - "今月の予約○件" 등 실적 톤
  - 호스트 인터뷰·사례 (허락 하에)
  - 한국인 게스트 트렌드·수요 정보

### 3.3 관리대행사·부동산 네트워크
- **역할**: B2B, 한 번에 다수 숙소 확보
- **활동**:
  - 1社당 10% 수수료 등 조건 명확히
  - "メッセージ代行なし"로 부담 경감
  - 1社 계약 → 해당사 보유 숙소 일괄 등록

### 3.4 기존 호스트 추천
- **역할**: 구전, 신뢰 전이
- **활동**:
  - 추천 시 인센티브 (예: 수수료 1~2%p 할인 3개월)
  - "○○様のご紹介で登録" 문구로 신규 호스트 안심

## 4. LP(랜딩 페이지) 개선 제안

현재 `/lp/host` 구조를 유지하면서, **보틀넥 해소**용 블록을 추가.

### 4.1 추가 권장 섹션

| 섹션 | 위치 | 내용 |
|------|------|------|
| **실적·증거** | 3つの強み 위 | "登録ホスト○名 / 月間予約○件" 등 (실제 숫자로 업데이트) |
| **호스트의 목소리** | 3つの強み 아래 | 1~2건 짧은 후기 (허락된 호스트) |
| **등록이 쉬운 이유** | 料金 위 | "LINEで情報いただければ代行入力" 등 |
| **리스크 제로** | CTA 위 | "いつでも掲載停止可 / 一方的返金なし" 요약 |

### 4.2 CTA 강화
- 기존: "LINEで相談する" ✅ 유지
- 추가: "**まずは無料でお試し**" 문구로 심리적 부담 완화

---

## 5. 오퍼(제안) 설계

### 5.1 추천 오퍼: 「3ヶ月お試し」

- **내용**: 최초 3개월 수수료 무료 또는 절반 (예: 10% → 5%)
- **조건**: 1物件のみ、または 新規登録に限る
- **효과**: "해봐도 손해 없다" → 첫 등록 허들 대폭 하락

### 5.2 대안: 「代行登録サービス」

- **내용**: 에어비앤비 등 기존 등록 정보를 보내주면, 운영진이 OTA에 대신 입력
- **조건**: LINE 상담 시 신청
- **효과**: "귀찮음" 제거 → 등록 완료율 상승

## 6. 실행 로드맵

| Phase | 기간 | 내용 |
|-------|------|------|
| **Phase 1** | 1~2주 | LP에 "실적·등록쉬움·리스크제로" 블록 추가, 오퍼(3ヶ月お試し or 代行登録) 결정 |
| **Phase 2** | 2~4주 | LINE 자동응답·상담 스크립트 정비, 대리입력 프로세스 구축 |
| **Phase 3** | 1개월~ | 호스트 1~2명 인터뷰 → 사례 공개, 관리대행사 1~2사 접촉 |
| **Phase 4** | 지속 | X 실적 발신, 추천 인센티브 운영 |
