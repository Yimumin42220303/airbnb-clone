# 프로덕션에서 카드 결제 테스트하는 방법

현재 도쿄민박 OTA(tokyominbak.net)는 **포트원 + KG이니시스**로 카드 결제를 연동해 두었습니다. 아래 순서대로 진행하면 프로덕션에서 테스트 결제를 할 수 있습니다.

---

## 1. 사전 확인

- Vercel **Production** 환경에 아래가 설정되어 있어야 결제창이 뜹니다.
  - `NEXT_PUBLIC_PORTONE_STORE_ID`
  - `NEXT_PUBLIC_PORTONE_CHANNEL_KEY`
  - `PORTONE_API_SECRET`
- 포트원 채널에 **실서비스 URL**(예: `https://tokyominbak.net`)이 등록되어 있어야 합니다.
- **이니시스 V2** 사용 시 결제창에서 **휴대폰 번호**(10~11자리)가 필요합니다. 예약 확인 단계에서 입력하는 전화번호가 사용됩니다.

---

## 2. 테스트 결제 진행 순서

### A. 즉시 예약 숙소로 테스트 (가장 짧은 경로)

1. **https://tokyominbak.net** 접속 후 **Google 로그인**
2. **숙소 검색** → **즉시 예약 가능**이 있는 숙소 선택
3. **체크인/체크아웃·인원** 선택 후 **예약하기** 클릭
4. **예약 및 결제** 페이지에서  
   - 예약자 **이름, 이메일, 전화번호**(010-1234-5678 형식) 입력  
   - **「₩(금액) 결제하기」** 클릭
5. **결제** 페이지(`/booking/[id]/pay`)에서 다시 **결제하기** 버튼 클릭
6. **포트원(KG이니시스) 결제창**이 뜨면 **카드번호·유효기간·CVC·비밀번호 앞 2자리** 입력 후 결제

### B. 승인 후 결제 숙소로 테스트

1. 위 1~3까지 동일
2. **예약 확인** 페이지에서 예약자 정보 입력 후 **예약 요청하기** 클릭 → 메시지/예약 요청 완료 페이지로 이동
3. **호스트 계정**으로 로그인해 해당 예약 **승인**
4. **게스트 계정**으로 **내 예약** 또는 **메시지**에서 **결제하기** 링크 클릭
5. 결제 페이지에서 **결제하기** → 결제창에서 카드 정보 입력 후 결제

## 3. 간편하게 테스트 결제하는 방법

### 3-1. 모의 결제 (로컬·프리뷰 전용, 카드 없이)

실제 카드 입력 없이 **결제 완료 플로우**만 빠르게 확인하고 싶다면 **모의 결제**를 사용하세요.

- **사용 환경**: 로컬(`npm run dev`) 또는 Vercel **Preview** 배포. **프로덕션(tokyominbak.net)에는 설정하지 마세요.**
- **설정**: 로컬은 `.env`에, **Preview는 Vercel 환경 변수**에 아래 두 값을 넣습니다.
  - `ENABLE_MOCK_PAYMENT=1`
  - `NEXT_PUBLIC_ENABLE_MOCK_PAYMENT=1`
- **사용법**: 결제 페이지(`/booking/[id]/pay`)에 **「테스트 결제 (모의 · 카드 없음)」** 버튼이 나타납니다. 클릭하면 PG 호출 없이 결제 완료 처리되고, 메시지창 또는 내 예약으로 이동합니다.
- **용도**: 결제 후 리다이렉트·메시지·이메일·알림 등 플로우 검증용. 실제 출금·환불은 발생하지 않습니다.

#### Vercel Preview로 검증하는 방법

1. **Preview 배포 만들기**
   - **방법 A**: GitHub에서 **main이 아닌 브랜치**를 만들고 push하면, Vercel이 자동으로 해당 브랜치용 **Preview** URL을 만듭니다.
   - **방법 B**: **Pull Request**를 열면 PR마다 Preview URL이 생성됩니다. (예: `airbnb-clone-git-xxx-chris-projects.vercel.app`)

2. **Preview 전용 환경 변수 설정**
   - [Vercel 대시보드](https://vercel.com) → 해당 프로젝트 → **Settings** → **Environment Variables**
   - 아래 두 변수를 추가하고, **Environment**에서 **Preview**만 체크합니다. (Production은 체크하지 마세요.)
     - `ENABLE_MOCK_PAYMENT` = `1`
     - `NEXT_PUBLIC_ENABLE_MOCK_PAYMENT` = `1`
   - 저장 후 **다음 Preview 배포부터** 적용됩니다. (이미 떠 있는 Preview는 **Redeploy** 하면 반영됩니다.)

3. **검증 순서**
   - Preview URL(예: `https://airbnb-clone-xxx.vercel.app`)에 접속합니다.
   - Google 등으로 **로그인** → 즉시예약 숙소로 **예약 진행** → 결제 페이지까지 이동합니다.
   - **「테스트 결제 (모의 · 카드 없음)」** 버튼이 보이면 클릭합니다.
   - §6 체크리스트대로 **게스트** 화면(메시지창 이동, 메시지 내용, 내 예약)을 확인합니다.
   - **호스트** 계정으로 로그인해 **알림·예약 목록·메시지**를 확인합니다.

4. **주의**
   - Preview도 **프로덕션과 같은 DB**를 쓸 수 있습니다. (Vercel에서 Preview용 `DATABASE_URL`을 따로 두지 않았다면 동일 DB.) 모의 결제는 DB에 예약·결제 완료로 기록되므로, 테스트용 계정/숙소로 진행하는 것이 좋습니다.
   - Preview URL을 포트원 채널에 등록하지 않아도 **모의 결제**는 PG를 타지 않으므로 그대로 사용 가능합니다.

### 3-2. 프로덕션에서 카드 테스트가 번거로운 경우

- **테스트 연동 채널**을 쓰면 당일 23:00~23:50에 **자동 취소(환불)** 되므로, 매번 수동 환불할 필요가 없습니다. [포트원 콘솔](https://admin.portone.io/)에서 채널을 **테스트 연동**으로 추가해 두세요.
- **국민/카카오뱅크/롯데** 등 특정 카드가 테스트에서 막히면, **신한·현대·삼성** 등 다른 발급사 카드로 테스트하면 됩니다. (테스트 연동 시에도 당일 밤 자동 취소됩니다.)
- **브라우저 자동완성**으로 카드 정보를 저장해 두면 매번 입력하는 수고를 줄일 수 있습니다. (개인 기기에서만 권장)

---

## 4. 카드 사용 시 유의사항

| 구분 | 내용 |
|------|------|
| **테스트 연동 채널** | 실제 카드로 1회 결제(출금)되며, **매일 23:00~23:50(KST)** 사이에 해당 건이 **자동 취소(환불)** 됩니다. |
| **실 연동 채널** | 실제 결제·정산되며 자동 취소 없음. 운영 테스트 시 소액으로 진행하는 것이 안전합니다. |
| **국민카드/카카오뱅크** | KG이니시스 테스트 연동에서는 **미지원**. 다른 발급사 카드로 테스트하세요. |
| **테스트용 가상 카드** | KG이니시스/포트원이 공식 테스트 카드번호를 제공하는지는 [포트원 관리자 콘솔](https://admin.portone.io/) → 채널 설정 또는 [포트원 헬프센터](https://help.portone.io/)에서 확인하세요. 없으면 **본인 실제 카드**(테스트 연동 시 당일 밤 자동 취소)로 결제 흐름만 확인하면 됩니다. |

---

## 5. 결제 후 확인

- 결제 성공 시 **예약 완료** 페이지 또는 **내 예약**으로 이동합니다.
- **마이페이지 → 내 예약**에서 해당 예약이 **결제 완료**로 보이면 정상 반영된 것입니다.
- (테스트 연동인 경우) 당일 23:00~23:50 사이에 자동 취소되면 **예약 취소·환불** 상태로 바뀝니다.

---

## 6. 결제 완료 후 호스트·게스트 UX/UI 검증 체크리스트

결제 완료 플로우(리다이렉트, 메시지, 알림, 이메일 등)를 검증할 때 아래를 순서대로 확인하세요. **모의 결제**를 쓰면 카드 입력 없이 빠르게 반복 검증할 수 있습니다.

### 6-1. 게스트(결제한 사람) 측 확인

| # | 확인 항목 | 기대 결과 |
|---|-----------|-----------|
| 1 | **결제 성공 후 이동** | 즉시예약·승인후결제 모두 **호스트와의 메시지창**(`/messages/[id]`)으로 이동 |
| 2 | **메시지 목록** | 해당 예약 대화방이 **메시지** 목록에 보임 |
| 3 | **대화 내용** | **즉시예약**: 도쿄민박 발신 「결제가 정상적으로 완료되었으며…」 메시지 표시. **승인후결제**: 호스트 발신 「예약감사합니다. 3일내에 체크인방법…」 메시지 표시 |
| 4 | **내 예약** | 마이페이지 → 내 예약에서 해당 건이 **예약 확정**·**결제 완료** 상태로 표시 |
| 5 | **예약 상세** | 숙소 보기, 메시지, 예약 취소 등 버튼/링크 정상 동작 |

### 6-2. 호스트(숙소 등록자) 측 확인

| # | 확인 항목 | 기대 결과 |
|---|-----------|-----------|
| 1 | **알림** | 상단 알림 아이콘에 **「(게스트명)님이 결제를 완료했어요. 예약이 확정되었습니다.」** 표시, 클릭 시 호스트 예약 목록으로 이동 |
| 2 | **호스트 예약 목록** | 호스트 → 예약 관리에서 해당 예약이 **확정**·**결제 완료** 상태로 표시 |
| 3 | **메시지** | 호스트 메시지 목록에 해당 게스트와의 대화방 표시, 환영 메시지(즉시예약 시 도쿄민박 문구, 승인후결제 시 호스트 자동 문구) 확인 |
| 4 | **이메일** | (이메일 설정된 경우) 게스트·호스트에게 결제 완료 안내 메일 발송 |

### 6-3. 모의 결제로 빠르게 검증하는 순서

1. `.env`에 `ENABLE_MOCK_PAYMENT=1`, `NEXT_PUBLIC_ENABLE_MOCK_PAYMENT=1` 설정 후 로컬 실행.
2. **게스트 계정**으로 로그인 → 즉시예약 숙소로 예약 진행 → 결제 페이지에서 **「테스트 결제 (모의 · 카드 없음)」** 클릭.
3. 위 **6-1** 항목대로 게스트 화면 확인 (리다이렉트 → 메시지창 → 메시지 내용 → 내 예약).
4. **호스트 계정**으로 로그인(또는 시크릿/다른 브라우저) → 위 **6-2** 항목대로 호스트 화면 확인 (알림, 예약 목록, 메시지).
5. 필요 시 **승인 후 결제** 숙소로 동일하게 모의 결제 후, 호스트 환영 메시지 등 차이만 추가 확인.

## 7. 문제 발생 시

- **결제창이 안 뜸**  
  → Vercel Production에 `NEXT_PUBLIC_PORTONE_*`, `PORTONE_API_SECRET` 설정 여부, 포트원 채널에 tokyominbak.net URL 등록 여부 확인.
- **「휴대폰 번호가 필요합니다」**  
  → 예약 확인 단계에서 **긴급연락용 전화번호**를 010-XXXX-XXXX 형식으로 입력했는지 확인. 마이페이지에서 본인 전화번호가 있어도, 결제 시에는 예약 시 입력한 번호가 사용됩니다.
- **결제 검증 실패**  
  → `PORTONE_API_SECRET`(V2 Secret Key)이 포트원 콘솔 값과 일치하는지 확인.

자세한 PG·채널 설정은 [포트원-PG-설정-가이드.md](포트원-PG-설정-가이드.md)를 참고하세요.
