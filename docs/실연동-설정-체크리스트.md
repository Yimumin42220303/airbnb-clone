# 실연동(실제 결제) 설정 체크리스트

포트원 + KG이니시스 실연동이 올바르게 되어 있는지 확인할 때 아래 항목을 순서대로 체크하세요.

---

## 1. KG이니시스 (상점관리자)

- [ ] KG이니시스 **실계약** 완료됨 (카드사 심사 완료된 MID)
- [ ] [상점관리자](https://iniweb.inicis.com/security/login.do) 로그인 가능
- [ ] **MID** 확인됨 (10자리, 예: MOIxxxxxxxx)
- [ ] **웹 signkey** 상점정보 → 부가정보 → 웹 signkey [조회] 가능
- [ ] **INIAPI key** (KEY·IV) 상점정보 → 부가정보 → INIAPI key [조회/생성] 가능

---

## 2. 포트원 채널 (실연동)

- [ ] [포트원 관리자 콘솔](https://admin.portone.io/) 로그인 가능
- [ ] **결제연동** → **채널관리** → **실연동** 탭에 KG이니시스 채널이 있음
- [ ] 해당 채널 **연동모드** = 실연동
- [ ] **결제 모듈** = 결제창 일반/정기결제 API 일반/정기결제 (V2)
- [ ] 채널에 **PG상점아이디(MID)**, **웹결제 signkey**, **INIAPI key(IV)** 입력되어 있음
- [ ] 채널의 **Channel Key** 복사해 둠 (`channel-key-xxxx...`)

---

## 3. 포트원 Store / API Keys

- [ ] **Store ID** 확인됨 (상점·계정관리 또는 식별코드 API Keys에서 `store-xxxx...`)
- [ ] **V2 Secret Key** (API Secret) 복사해 둠 → 서버용, 프론트에 노출 금지

---

## 4. 포트원 URL 설정

- [ ] **결제 허용 URL** (또는 도메인 허용)에 실제 서비스 주소 등록됨  
  예: `https://tokyominbak.net` (채널 상세 또는 추가 설정 관리에서)
- [ ] **결제알림(Webhook) 관리** → **실연동** 선택
- [ ] **Endpoint URL** = `https://본인도메인/api/webhooks/portone` (예: `https://tokyominbak.net/api/webhooks/portone`)
- [ ] **Content Type** = `application/json`
- [ ] (선택) **웹훅 시크릿** 발급 후 값 복사해 둠 → `.env`의 `PORTONE_WEBHOOK_SECRET`에 보관

---

## 5. 환경 변수 – 로컬 (.env)

- [ ] `NEXT_PUBLIC_PORTONE_STORE_ID` = 포트원 Store ID
- [ ] `NEXT_PUBLIC_PORTONE_CHANNEL_KEY` = **실연동** 채널의 Channel Key (테스트 채널 키 아님)
- [ ] `PORTONE_API_SECRET` = 포트원 API Keys → V2 Secret Key
- [ ] (선택) `PORTONE_WEBHOOK_SECRET` = 웹훅 시크릿 발급 값 (`whsec_...`)
- [ ] `NEXT_PUBLIC_PORTONE_TEST_MODE` 없음 또는 `false` (실연동이면 테스트 모드 끄기)
- [ ] (정기결제 사용 시) `NEXT_PUBLIC_PORTONE_BILLING_CHANNEL_KEY` = 실연동 빌링 채널 키
- [ ] 프로덕션용 **모의 결제** 변수 없음: `ENABLE_MOCK_PAYMENT`, `NEXT_PUBLIC_ENABLE_MOCK_PAYMENT` 는 로컬/Preview 전용

---

## 6. 환경 변수 – Vercel (배포)

- [ ] **Production** 환경에 `NEXT_PUBLIC_PORTONE_STORE_ID` 설정
- [ ] **Production** 환경에 `NEXT_PUBLIC_PORTONE_CHANNEL_KEY` = 실연동 채널 키
- [ ] **Production** 환경에 `PORTONE_API_SECRET` 설정
- [ ] (선택) **Production** 환경에 `PORTONE_WEBHOOK_SECRET` 설정
- [ ] Production에는 `ENABLE_MOCK_PAYMENT`, `NEXT_PUBLIC_ENABLE_MOCK_PAYMENT` **설정하지 않음**

---

## 7. 애플리케이션 동작 확인

- [ ] 실제 서비스 URL(예: https://tokyominbak.net)에서 **결제하기** 버튼이 보임
- [ ] 결제하기 클릭 시 **KG이니시스 결제창**이 정상적으로 뜸 (차단/오류 없음)
- [ ] **소액 1건** 결제 테스트 후 결제 완료 페이지 또는 내 예약으로 이동
- [ ] **포트원 콘솔** → 결제내역에서 해당 결제 건 확인
- [ ] **KG이니시스 상점관리자**에서 동일 건 확인
- [ ] (선택) 결제 완료 시 **웹훅** 수신으로 예약 상태가 결제완료로 갱신되는지 확인

---

## 8. 문제 발생 시 점검

| 증상 | 확인할 것 |
|------|------------|
| 결제창이 안 뜸 | 결제 허용 URL에 현재 도메인 등록 여부, `NEXT_PUBLIC_PORTONE_*` 값(Store ID·Channel Key) |
| 결제 검증 실패 | `PORTONE_API_SECRET` 값이 포트원 API Keys와 일치하는지 |
| 웹훅 후 예약 미반영 | Endpoint URL 정확한지, 서버 로그에 웹훅 수신/에러 있는지 |
