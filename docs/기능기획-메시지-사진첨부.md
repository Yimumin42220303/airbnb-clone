# 기능 기획: 메시지창 사진 첨부 (게스트·호스트)

에어비앤비 스타일 UX/UI를 참고한 **메시지에서 사진/동영상 첨부** 기능 구현 기획입니다.  
게스트와 호스트 모두 사진 파일을 첨부해 보낼 수 있도록 합니다.

---

## 1. 참고 UX/UI (에어비앤비)

- **입력창 왼쪽 "+" 버튼**: 추가 기능 진입점
- **"+ " 탭 시**: 흰색 둥근 모서리 **모달** 표시
- **모달 메뉴 항목**:
  - 빠른 답변 전송하기
  - 전송 예약된 빠른 답변 보기 (호스트 전용)
  - **사진 또는 동영상 추가** ← 본 기능
  - 추천 장소/활동 공유하기 (준비 중)
  - 전화 통화 버튼 추가 (준비 중)
- **"사진 또는 동영상 추가" 선택** → 기기 파일 선택기(갤러리/카메라) → 선택한 미디어를 메시지에 첨부

## 2. 현재 구조 요약

| 구분 | 내용 |
|------|------|
| 메시지 입력 UI | `src/app/messages/[id]/MessageThread.tsx` |
| "+" 버튼 노출 | **호스트일 때만** 노출 (`isHost && ...`) → 게스트는 "+" 없음 |
| 플러스 메뉴 | `MessagePlusMenu.tsx` — "사진 또는 동영상 추가" 메뉴는 있으나 `onClick` 없음(준비 중) |
| 메시지 API | `POST /api/conversations/[id]/messages` — `body`(텍스트)만 수신 |
| DB | `Message` 모델 — `body`, `senderId`, `conversationId` 만 존재 (첨부 필드 없음) |
| 업로드 | `/api/upload/listing`, `/api/upload/profile` — Vercel Blob 또는 Cloudinary 사용 |

## 3. 목표 UX (도쿄민박 적용)

1. **게스트·호스트 공통**
   - 메시지 입력창 **왼쪽**에 "+" 버튼 항상 노출 (에어비앤비와 동일 위치).
   - "+" 탭 → **메시지 옵션 모달** 표시 (기존 `MessagePlusMenu` 활용·확장).

2. **"사진 또는 동영상 추가" 선택 시**
   - 모달 닫기 후 **파일 선택** (이미지: JPEG/PNG/WebP/GIF, 1차는 **사진만** 지원 권장).
   - 선택한 이미지를 **입력창 위**에 썸네일로 **미리보기** 표시 (삭제 버튼 포함).
   - (선택) 짧은 **캡션(텍스트)** 입력 가능.
   - **전송** 클릭 시: 이미지 업로드 → URL 확정 후 메시지 전송 (텍스트 없이 이미지만 전송 가능).

3. **메시지 목록 표시**
   - 텍스트 메시지: 기존처럼 말풍선 + `body`.
   - 이미지 첨부 메시지: 말풍선 안에 **썸네일 + (캡션이 있으면) 캡션** 표시. 클릭 시 큰 이미지 보기(선택).

## 4. 기능 범위 제안

| 항목 | 1차 구현 제안 | 비고 |
|------|----------------|------|
| 미디어 종류 | **사진만** (JPEG/PNG/WebP/GIF) | 동영상은 2차 (용량·인코딩 이슈) |
| 메시지당 첨부 수 | **1장** | 다중 첨부는 2차 |
| 파일 크기 | **최대 4MB** | 기존 listing 업로드와 동일 |
| 텍스트 | 이미지와 함께 보낼 수 있는 **캡션(선택)** | `body`에 캡션 저장, 이미지는 `imageUrl` |
| "+" 버튼 | **게스트·호스트 모두** 노출 | `MessageThread`에서 `isHost` 조건 제거 후 메뉴는 역할별로 제어 |

## 5. 데이터 구조

### 5.1 DB 스키마 변경

**Option A (간단)**  
- `Message`에 선택 필드 추가:
  - `imageUrl String?` — 첨부 이미지 URL (1장만).

**Option B (확장용)**  
- `MessageAttachment` 테이블:
  - `id`, `messageId`, `url`, `type`('image'|'video'), `createdAt`
  - 나중에 동영상·다중 첨부 시 재사용 가능.

**권장**: 1차는 **Option A**로 진행. 필요 시 나중에 Option B로 마이그레이션.

### 5.2 API 응답 확장

- `GET /api/conversations/[id]/messages`  
  - 각 메시지에 `imageUrl?: string | null` 포함.
- `POST /api/conversations/[id]/messages`  
  - 요청: `body`(텍스트/캡션, 선택), `imageUrl`(선택).  
  - `body`와 `imageUrl` 둘 다 없으면 400.

---

## 6. API 설계

### 6.1 메시지용 이미지 업로드

- **경로**: `POST /api/upload/message`  
- **역할**: 로그인 사용자가 **메시지 첨부용** 이미지 1장 업로드.
- **인증**: 로그인 필수 (기존 upload와 동일).
- **요청**: `FormData` — `file` (단일 파일).
- **제한**: 이미지 타입만, 최대 4MB.
- **저장소**: 기존과 동일 (Vercel Blob 또는 Cloudinary).  
  - 경로/prefix는 `message/` 또는 `messages/` 등으로 구분 권장.
- **응답**: `{ url: string }` — 이후 메시지 전송 시 이 URL을 `imageUrl`로 전달.

### 6.2 메시지 전송

- **기존**: `POST /api/conversations/[id]/messages` — `{ body: string }`.
- **변경**:
  - `body`: 선택 (빈 문자열 허용). 이미지만 보낼 때는 "".
  - `imageUrl`: 선택. 있으면 해당 URL을 `Message.imageUrl`에 저장.
  - 검증: `body`와 `imageUrl` **둘 다 없으면** 400.
  - 권한·레이트 리밋: 기존과 동일.

## 7. 화면·플로우

### 7.1 "+" 버튼 및 모달

1. **MessageThread**
   - "+" 버튼을 **호스트만**이 아니라 **모든 참여자(게스트·호스트)** 에게 노출.
   - 클릭 시 `MessagePlusMenu` 오픈 (기존 컴포넌트 재사용).

2. **MessagePlusMenu**
   - "사진 또는 동영상 추가"에 `onClick` 연결.
   - 콜백: `onAddPhotoVideo?: () => void`  
     → 부모에서 파일 선택기 오픈 + 미리보기 상태 관리.

3. **게스트용 번역**
   - 메뉴 문구는 이미 `messageMenu.addPhotoVideo` 등으로 호스트 i18n에 있음.
   - 게스트 화면에서는 동일 메뉴를 **한국어**로만 노출해도 무방 (필요 시 공통 i18n 확장).

### 7.2 사진 첨부 플로우

1. 사용자가 "+" → "사진 또는 동영상 추가" 선택.
2. 모달 닫기 → **파일 선택** (input type="file" accept="image/*").
3. 선택한 파일 → **미리보기**를 입력창 **위**에 표시 (썸네일 + 삭제 버튼).
4. (선택) 캡션 입력.
5. **전송** 클릭:
   - 먼저 `POST /api/upload/message`로 이미지 업로드 → `url` 수신.
   - 이어서 `POST /api/conversations/[id]/messages`에 `{ body: 캡션, imageUrl: url }` 전송.
6. 전송 성공 시 미리보기 제거, 입력 초기화. 메시지 목록에 이미지 메시지 추가 (optimistic + 서버 응답 반영).

### 7.3 메시지 목록 표시

- `messages` 항목에 `imageUrl`이 있으면:
  - 말풍선 안에 **썸네일** 표시 (예: `next/image` 또는 `<img>`로 작은 크기).
  - `body`가 있으면 썸네일 아래 또는 옆에 캡션 표시.
- (선택) 썸네일 클릭 시 라이트박스/모달로 큰 이미지 보기.
