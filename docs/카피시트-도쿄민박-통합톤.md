## 1. 브랜드 프레임

| 항목 | 내용 |
|------|------|
| **한 줄** | 합리적인 가격 + 한국어로 끝까지 챙기는 도쿄 숙소 예약 창구 |
| **1순위 메시지** | 한국어 책임 창구 (예약~체크아웃·환불 접수) |
| **2순위 메시지** | 합리적인 요금 (최저가 보장 아님, 총액 비교 권장) |
| **타깃** | 도쿄 여행 한국인, 해외 숙소 플랫폼 불안·일본어 부담 |

### 쓰지 말 것

- 프리릴리스 / 테스트 결제만
- 최저가 보장 / 무조건 환불 / 전액 보상
- 「에어비앤비보다 무조건 ○○% 저렴」(일괄 단정)
- 무한 책임 / 모든 문제 100% 해결

### 톤

- **담백·구체** (날짜·조건·채널을 말할 수 있을 때만)
- **과장 없음**, 법률 검토 전 강한 보장 문구 금지
- **「도쿄민박이 직접 대응」** + 필요 시 「숙소·현지 파트너와 함께 확인」

## 5. Meta 광고 카피 (초안)

광고 관리자에 그대로 붙여 넣을 수 있는 초안. 랜딩은 캠페인 목적에 맞게 `/trust` 또는 `/search` 분리.

### A. 전환 (신뢰+가격) → `/trust`

| 필드 | 문구 |
|------|------|
| Primary | 처음 보는 해외 숙소 플랫폼, 불안하시죠? 도쿄민박은 예약 전 문의부터 체크인·숙박 중 문제·환불까지 한국어로 직접 대응합니다. 합리적인 요금으로 도쿄 현지 숙소를 확인해 보세요. |
| Headline | 도쿄 숙소, 한국어로 끝까지 챙겨 드립니다 |
| Description | 안심예약센터에서 결제·환불·운영 방식을 확인할 수 있습니다. |

### B. 유입 (가격 관심) → `/search`

| 필드 | 문구 |
|------|------|
| Primary | 도쿄 여행 숙소, 가격만 보고 결제하기 전에 한 번 더 확인하세요. 도쿄민박은 합리적인 요금과 한국어 운영대응을 함께 제공합니다. 취소·환불 조건은 예약 전에 확인할 수 있습니다. |
| Headline | 합리적인 가격으로 도쿄 숙소 예약 |
| Description | 에어비앤비와 총액 기준으로 비교해 보세요. |

### C. 고려 (결제 불안) → `/trust`

| 필드 | 문구 |
|------|------|
| Primary | 결제하면 연락이 끊기는 게 걱정되시나요? 결제 후에도 도쿄민박 고객지원팀이 한국어로 안내합니다. KG이니시스 안전결제, 숙소별 환불 일정도 예약 전에 확인 가능합니다. |
| Headline | 결제 후에도 도쿄민박이 함께합니다 |
| Description | 안심예약센터 · 사업자 정보 공개 |

### D. 리타겟 (방문 후) → `/search`

| 필드 | 문구 |
|------|------|
| Primary | 아까 보신 도쿄 숙소, 아직 고민 중이신가요? 취소·환불 날짜와 예약 확정 방식은 예약 화면에서 확인할 수 있습니다. 궁금한 점은 한국어로 문의해 주세요. |
| Headline | 예약 전에 조건부터 확인하세요 |
| Description | 도쿄민박 직접 운영대응 |

**Meta CAPI / 픽셀:** 기존 ViewContent → InitiateCheckout → Purchase 유지. 신뢰 캠페인은 `/trust` 랜딩 + Purchase 최적화는 `/search`·숙소 상세 병행 권장.
