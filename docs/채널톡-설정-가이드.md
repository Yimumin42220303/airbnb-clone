# 채널톡 퍼널 최적화 — 콘솔 설정 가이드

코드가 채널톡으로 보내는 데이터(태그·이벤트·프로필)를 활용해 관리자 콘솔에서 설정할 항목입니다.
우선순위 순서대로 정리했습니다. (소요: 전체 약 2~3시간)

## 코드가 보내는 데이터 (설정에서 활용 가능)

| 종류 | 값 | 발생 시점 |
|---|---|---|
| 태그 | `listing_inquiry`, `listing_{숙소ID}` | 숙소 상세에서 문의 클릭 |
| 태그 | `pay_inquiry` | 결제 페이지에서 문의 클릭 (신규) |
| 이벤트 | `Guest listing inquiry` | 숙소 문의 (숙소·날짜·인원 포함) |
| 이벤트 | `Guest pay inquiry` | 결제 문의 (예약ID·금액 포함) (신규) |
| 프로필 | `inquiryListingTitle`, 체크인/아웃, 인원 | 숙소 문의 시 |
| 프로필 | `payInquiryBookingId`, `payInquiryTotalPrice` | 결제 문의 시 (신규) |
| 봇 메시지 | 결제 리마인더·자동취소 안내 (결제 링크 포함) | 서버 자동 발송 (신규) |

## 1. 운영시간·부재중 응답 (15분) — 가장 먼저

**설정 → 운영시간**
- 운영시간 설정 (예: 10:00–22:00 KST). 여행객 특성상 저녁 문의가 많으므로 가능하면 22시까지.
- 부재중 자동응답: "지금은 상담 가능 시간이 아니에요. 메시지를 남겨주시면 운영시간에 바로 답변드립니다. 급한 체크인 문제는 ☎ 010-4689-4411"
- **연락처 수집 켜기**: 부재중 메시지 작성 시 전화번호/이메일 필수 입력 → 비로그인 방문자 리드 확보의 핵심.

## 2. 서포트봇(워크플로우) — 첫 응대 자동화 (1시간)

**워크플로우 → 새 워크플로우**, 시작 분기 4개:

1. **숙소·예약 문의** → 날짜/인원 확인 질문 → 상담원 연결. `listing_inquiry` 태그가 있으면 어떤 숙소인지 프로필에 이미 있음.
2. **결제가 안 돼요** → `pay_inquiry` 태그 고객 우선 배정 + "카드사 한도/해외결제 차단을 확인해 주세요" 자동 안내 → 미해결 시 상담원. **이 분기가 미결제 회수와 직결됩니다.**
3. **체크인/이용 안내** → FAQ 답변 (체크인 방법, 와이파이, 짐 보관) → 미해결 시 상담원.
4. **취소·환불** → 취소정책 페이지 링크 + 예약번호 입력 요청 → 상담원.

각 분기 끝에 비로그인 고객이면 연락처 수집 단계 추가.

## 3. 마케팅 메시지(캠페인) — 이탈 시점 개입 (30분)

**마케팅 → 캠페인**, 조건은 이벤트/태그 기준:

| 캠페인 | 트리거 | 메시지 |
|---|---|---|
| 결제 이탈 케어 | `Guest pay inquiry` 발생 또는 결제 페이지 60초+ 체류 | "결제 중 막히는 부분이 있으면 바로 도와드릴게요" |
| 문의 후 미예약 | `Guest listing inquiry` 후 24시간 내 결제 없음 | "문의하신 {숙소}, 날짜가 마감되기 전에 확인해 보세요" |
| 재방문 환영 | 재방문 + 과거 `listing_inquiry` 태그 | "지난번 보신 숙소 다시 보기" |

※ 발송량이 적은 초기에는 1번만 켜도 충분합니다.

## 4. ALF(AI 에이전트) — 반복 문의 자동 응답 (30분)

**ALF 설정 → 지식 소스 등록**: 안심예약센터(/trust), 자주 묻는 질문(/about FAQ), 취소·환불 정책(/agreement), 체크인 일반 안내.
- 처음에는 "답변 후 상담원 연결 제안" 모드로 보수적으로 시작.
- 결제·환불 관련 질문은 ALF가 단정하지 않고 상담원 연결하도록 제외 키워드 설정.

## 5. 상담 운영 규칙 (15분)

- **태그 자동 분류**: `pay_inquiry` → 우선순위 높음 배정 (결제 직전 고객 = 가장 뜨거운 리드)
- 고객 프로필 사이드바에 `payInquiryBookingId`, `inquiryListingTitle` 표시 항목 고정 → 상담원이 묻지 않고 바로 답변
- 첫 응답 목표: 운영시간 내 5분. 채널톡 통계에서 첫 응답 시간 주간 모니터링.

## 측정 (GA4 이벤트 — 이미 계측됨)

- `channel_talk_click` (source_page: listing / pay) → 진입점별 클릭
- `channel_talk_open` → 실제 오픈
- 주간 체크: 문의 수 → 문의 후 24h 내 예약 전환율, `pay_inquiry` 후 결제 완료율
