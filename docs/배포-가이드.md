---

## Cron (Hobby 플랜 제한)

Vercel Hobby 플랜은 cron이 **하루 1회**만 실행 가능합니다.

- `charge-deferred`: 매일 0시 (자정)
- `beds24-price-sync`: 매일 6시 (6시간마다 → 1회/일로 조정)

Pro 플랜으로 업그레이드하면 `beds24-price-sync`를 6시간마다(`0 */6 * * *`)로 변경 가능합니다.

## Git push + Deploy Hook

1. `npm run deploy` → git add, commit, push
2. push 후 Deploy Hook 호출 (설정 시)
3. Deploy Hook은 Vercel 프로젝트 Settings → Git → Deploy Hooks에서 생성

**주의**: Deploy Hook은 **해당 프로젝트가 연결된 저장소/브랜치** 기준으로 배포합니다.  
minbaktokyos용 Hook은 minbaktokyos 프로젝트에서, chris용 Hook은 chris 프로젝트에서 생성해야 합니다.

- minbaktokyos 설정: `npm run setup:deploy-hook` (기본)
- chris-projects: `VERCEL_TEAM=chris npm run setup:deploy-hook`

## 배포가 안 될 때

1. **Vercel 대시보드에서 팀 확인**  
   - tokyominbak.net → minbaktokyos-projects  
   - airbnb-clone-six-hazel-53 → chris-projects

2. **CLI 직접 배포로 우회**  
   - `.env`에 VERCEL_ORG_ID, VERCEL_PROJECT_ID 설정  
   - `npm run deploy:cli`

3. **GitHub 연동 확인**  
   - Vercel → 프로젝트 → Settings → Git  
   - GitHub 저장소 연결 여부 확인  
   - GitHub → 저장소 → Settings → Webhooks에서 Vercel webhook 에러 확인

4. **Deploy Hook 동작**  
   - Deploy Hook 응답은 성공인데 배포가 안 보이면  
   - 해당 프로젝트가 아닌 다른 팀 대시보드를 보고 있을 수 있음

5. **Beds24 가격이 표시되지 않을 때**  
   - Vercel → 프로젝트 → Settings → Environment Variables  
   - `BEDS24_REFRESH_TOKEN` 이 Production/Preview 환경에 설정되어 있는지 확인  
   - 미설정 시 Beds24 API 호출이 실패하고 기본 가격만 표시됨

## 명령 요약

| 명령 | 설명 |
|------|------|
| `npm run deploy` | git push + (선택) Deploy Hook 트리거 |
| `npm run deploy:cli` | 로컬 → Vercel 직접 배포 (권장) |
| `npm run deploy:vercel` | Deploy Hook 또는 API로만 트리거 |
| `npm run setup:deploy-hook` | Deploy Hook 설정 페이지 열기 |
| `npm run setup:vercel-link` | .vercel/project.json 생성 (deploy:cli용) |
