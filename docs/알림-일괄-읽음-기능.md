# お知らせポップ「すべてを既読」機能 企画

## 目的
お知らせ（通知）ポップに「すべてを既読」ボタンを追加し、未読のお知らせを一括で既読にできるようにする。

## 現状
- **UI**: `NotificationBell.tsx` でポップを表示。タイトル「お知らせ」、一覧、下に「すべてのお知らせを見る」リンク。
- **API**: 
  - `PATCH /api/notifications/[id]/read` … 1件ずつ既読
  - `GET /api/notifications` … 一覧取得
  - `GET /api/notifications/unread-count` … 未読件数
- **不足**: 一括既読用 API とポップ内ボタンがない。

## 実装内容

### 1. API
- **エンドポイント**: `PATCH /api/notifications/read-all`
- **処理**: ログインユーザーの未読通知（`readAt === null`）をすべて `readAt = now()` で更新。
- **認証**: 既存と同様に `getServerSession` で userId を取得し、本人の通知のみ更新。

### 2. 多言語
- **キー**: `notifications.markAllRead`
- **ko**: 「모두 읽음」
- **ja**: 「すべてを既読」

### 3. UI（NotificationBell）
- **配置**: ポップのヘッダー内、「お知らせ」タイトルの下（未読があるときのみ表示）。
- **挙動**:
  - クリックで `PATCH /api/notifications/read-all` を呼ぶ。
  - 成功時: 未読バッジを 0 にし、一覧の各項目を既読表示に更新。
  - ローディング中はボタンを無効化または「処理中」表示（任意）。
- **表示条件**: `unreadCount > 0` のときだけボタンを表示。
