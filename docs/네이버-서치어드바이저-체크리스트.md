# 네이버 서치어드바이저 · 신뢰 페이지 색인 체크리스트

사이트 소유확인: `layout.tsx` `naver-site-verification` 메타 태그 설정됨.

## 배포 후 운영 작업 (수동)

1. [네이버 서치어드바이저](https://searchadvisor.naver.com/) 로그인
2. **사이트맵 제출**: `https://tokyominbak.net/sitemap.xml` (또는 운영 `BASE_URL`/sitemap.xml)
3. **RSS 제출**: `https://tokyominbak.net/rss.xml` — 요청 → RSS 제출 → 위 URL 입력 → 확인
4. **수집 요청 URL** (배포 직후):
   - `/trust` (안심예약센터) — sitemap에 포함됨
   - `/about`
   - `/agreement`
   - 대표 숙소 상세 3~5개 URL
4. **검색 친화성** 진단에서 모바일·메타·canonical 확인

## 콘텐츠 (마케팅)

- 공식 블로그: 「도쿄민박 안심예약센터」 소개글
- 키워드: `도쿄민박`, `도쿄민박 후기`, `도쿄민박 믿을만한가요`
- **진짜 이용 후기** 우선 (체험단·협찬 시 광고 표시 의무)
