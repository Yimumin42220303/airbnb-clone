# 숙소 상세 페이지 · 스크롤 시 하단 고정 예약 바 기획

## 1. 목표

모바일에서 스크롤해도 **총 금액 + 예약하기**가 항상 보이도록 하단 고정 바(sticky bar)를 활용해 전환율과 UX를 개선한다.

---

## 2. 현재 구조

- **ListingDetailContent**: 좌측 본문(이미지·설명·리뷰) + 우측 예약 카드(BookingForm). 모바일에서는 예약 카드가 본문 아래로 흐름에 배치되어 있어, 스크롤을 많이 해야 예약하기에 도달함.
- **MobileStickyBookingBar** (이미 존재): `priceSummary`가 있을 때만 렌더링, `fixed bottom-0`, 1박 단가·총액·박수·예약하기 버튼 표시. 클릭 시 `#booking-form`의 `requestSubmit()` 호출.
- **BottomNav**: `fixed bottom-0`, `z-50`, 모바일만 표시. 높이 약 4rem + safe-area.

**이슈**: 스티키 바와 하단 네비가 둘 다 `bottom-0`이면 겹칠 수 있음. 스티키 바가 네비 뒤에 가려질 수 있음.

---

## 3. 개선 방향

### 3-1. 노출 조건 (스크롤 시 표시)

- **A안 (권장)**: 예약 폼(또는 예약 카드 영역)이 뷰포트에서 **밖으로 나갔을 때만** 스티키 바 표시.
  - 스크롤 올라가서 예약 폼이 다시 보이면 스티키 바 숨김 → 중복 CTA 제거.
  - 구현: `IntersectionObserver`로 예약 폼(또는 그 컨테이너)이 보이는지 감지, `isFormVisible === false`일 때만 스티키 바 표시.
- **B안**: 기존처럼 `priceSummary`만 있으면 항상 표시. 대신 **위치만** 하단 네비 위로 올림.

본 기획은 **A안(스크롤 시에만 표시)** 기준으로 작성.

### 3-2. 위치 (하단 네비와 겹침 방지)

- 모바일: `bottom: calc(4rem + env(safe-area-inset-bottom, 0px))` (하단 네비 높이만큼 띄움).
- PC(md 이상): 스티키 바 미노출 (기존 우측 sticky 예약 카드만 사용). `lg:hidden` 유지.

### 3-3. 표시 내용

- **날짜·인원 선택 완료 시** (`priceSummary` 유효):
  - **총 결제 금액** (기존처럼 청소비 포함 총액).
  - **예약하기** 버튼.
  - (선택) 1박 단가·N박 문구는 현재처럼 유지하거나, 공간이 좁으면 “총 ₩388,768 · 예약하기”처럼 한 줄로 단순화 가능.
- **미선택 시** (선택 사항):
  - 스티키 바를 “날짜·인원 선택 후 예약하기” 문구 + 클릭 시 예약 폼이 있는 곳으로 스크롤 이동하게 할 수 있음. 또는 현재처럼 `priceSummary` 없을 때는 스티키 바 비노출로 유지.

### 3-4. 동작

- 예약하기 클릭: 기존과 동일하게 `#booking-form`의 `requestSubmit()` 호출 (유효성 검사·페이지 이동은 폼 제출 로직 그대로 사용).
- 접근성: 버튼에 `aria-label`, 포커스 가능하게 유지.

## 5. 구현 순서 제안

1. **1단계**: 스티키 바 위치만 수정 (하단 네비 위로 올리기). → 즉시 겹침 해소.
2. **2단계**: IntersectionObserver로 “예약 폼이 화면에 안 보일 때만 스티키 바 표시” 적용. → 스크롤 시에만 고정 바 노출.
3. **3단계**: (선택) 미선택 시 안내 문구 + 스크롤 이동.

---

## 6. 주의사항

- 예약 폼이 있는 영역이 모바일 레이아웃에서 **한 번만** DOM에 존재하므로, Observer 타깃은 “예약 카드 전체” 또는 “BookingForm을 감싼 섹션” 하나로 두면 됨.
- `priceSummary`는 BookingForm의 `onPriceChange`로 상위에서 관리 중이므로, 스티키 바는 기존처럼 `priceSummary` prop만 받아 사용 가능.
- 하단 네비 높이(4rem + safe-area)는 `layout` / `BottomNav`와 동일 값 사용해 일관성 유지.

이 순서대로 적용하면 “스크롤 시 하단 고정 바로 총 금액 + 예약하기 항상 보이게” 하는 UX가 정리됩니다.
