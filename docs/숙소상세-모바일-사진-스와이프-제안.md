# 숙소 상세 · 모바일 사진 가로 스와이프 구현 방향

## 목표
- **모바일**: 메인 사진 영역에서 좌우 스와이프로 여러 장 넘기기
- **유지**: "사진 모두 보기" 버튼 그대로 두고, 탭 시 기존처럼 전체 사진 화면(AllPhotosOverlay)으로 이동

---

## 현재 구조 (ListingImageGallery.tsx)
- **PC (md+)**: 메인 1장 + 서브 4장 그리드. 클릭 시 Lightbox, "사진 모두 보기" → AllPhotosOverlay
- **모바일**: 그리드에서 서브 4장이 `hidden md:grid`로 숨겨져 **메인 1장만** 노출. "사진 모두 보기"만 누르면 전체 보기

---

## 구현 방향

### 1. 모바일만 캐러셀 적용
- **대상**: `images.length > 1` 일 때, **md 미만(모바일)** 에서만 가로 스와이프 영역 사용
- **md 이상**: 기존 그리드(메인 1 + 서브 2x2) 유지

### 2. 캐러셀 구현 방식: **CSS scroll-snap**
- **이유**: 의존성 없음, 터치 스와이프가 브라우저 기본 동작으로 자연스럽게 동작, 구현 단순
- **구조**:
  - 컨테이너: `flex overflow-x-auto overflow-y-hidden snap-x snap-mandatory` + `-webkit-overflow-scrolling: touch` (iOS 부드러운 스크롤)
  - 각 슬라이드: `flex-shrink-0 w-full min-w-full` (또는 `w-[100vw]` 등 1장이 화면 너비를 쓰도록) + `snap-center`
  - 세로 비율: 기존과 맞추려면 `aspect-square` 유지
- **동작**: 한 장씩 보이게 하고, 손가락으로 좌우 스와이프 시 다음/이전 사진으로 스냅

### 3. "사진 모두 보기" 버튼
- **위치·스타일**: 현재처럼 `absolute bottom-4 right-4` 유지
- **역할**: 클릭 시 `setShowAll(true)` → AllPhotosOverlay 열림 (변경 없음)
- **z-index**: 캐러셀 위에 떠 있도록 기존보다 높게 유지 (예: z-10)

### 4. 모바일에서 이미지 클릭
- **선택 A**: 각 슬라이드 탭 시 해당 인덱스로 **Lightbox** 열기 (한 장씩 크게 보기 + 좌우 화살표)
- **선택 B**: 탭 시 아무 동작 없이, "사진 모두 보기"만 전체 갤러리로 이동  
- **제안**: **선택 A** — 슬라이드 탭 시 Lightbox로 해당 사진 크게 보기 (기존 단일 메인 클릭과 동일한 UX)

### 5. 이미지 1장일 때
- 모바일에서도 캐러셀 불필요. 현재처럼 1장만 표시. "사진 모두 보기"는 이미 `images.length > 1`일 때만 렌더링되므로 변경 없음.

### 6. 수정 파일
- **단일 파일**: `src/components/listing/ListingImageGallery.tsx`
- **변경 요약**:
  - `images.length > 1`인 경우, 메인+서브 그리드 대신 **모바일에서는** 가로 스크롤 스냅 컨테이너로 `images` 전부를 나열
  - PC에서는 기존 `grid` 구조 유지 (md: 조건으로 기존 JSX 유지)
  - "사진 모두 보기" 버튼은 모바일/PC 공통으로 기존 위치에 그대로 두기

### 7. 선택 사항 (추후)
- 스크롤 인디케이터: 하단 중앙에 "1 / 5" 같은 점 또는 숫자 표시 (현재 스크롤 위치에 따라 갱신)
- 스크롤 시 버튼이 가려지지 않도록 그라데이션 또는 여백 처리 (이미 absolute로 오른쪽 하단에 두면 대부분 보임)
