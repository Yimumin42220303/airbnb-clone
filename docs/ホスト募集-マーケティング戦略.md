# ホスト募集 マーケティング戦略企画

> **目標KPI**: 宿泊施設数の確保（ホスト募集）  
> **ターゲット**: 日本の東京民泊ホスト（個人・管理代行会社）  
> **ボトルネック**: ①集客効果への疑問 ②未知のOTA・トラブル不安 ③登録・運営の煩雑さ

---

## 1. 日本人ホストの心理理解

### 1.1 民泊ホストの本質的ニーズ
- **安定収入**: 予約がコンスタントに入ってほしい
- **リスク回避**: トラブル・紛争・損害を避けたい
- **手間の最小化**: すでにAirbnb・Booking.comなどで忙しい中、新チャネル追加は負担
- **信頼**: 「この人・会社は信頼できるか」が決定的

### 1.2 日本特有の行動パターン
- **口コミ信頼**: 他ホスト・管理代行会社の紹介が強い
- **LINE志向**: メールよりLINEで相談・問い合わせ
- **段階的関係**: いきなり登録より「まず相談 → 小規模トライアル → 本格登録」を好む
- **損・トラブル回避**: 「登録しても損しないか」が最優先

## 2. ボトルネック別 解決戦略

### 2.1 ボトルネック①: 「登録しても集客に意味があるの？」

**核心**: 「効果がある」という**証拠**を見せること。

| 戦略 | 内容 | 優先度 |
|------|------|--------|
| **実績数字の公開** | 「登録ホスト○名、月間予約○件、平均滞在○泊」など具体的数値 | 高 |
| **ホスト事例・インタビュー** | 「Aホスト様は登録2週間で初予約」など短い声 | 高 |
| **ゲスト需要の証明** | 「韓国人ゲストの問い合わせが月○件、受け皿が足りていない」 | 高 |
| **シーズン・イベント連動** | 「もうすぐ繁忙期、今登録すれば露出チャンス」 | 中 |
| **無料お試し登録** | 「3ヶ月無料でお試し。効果がなければそのままおやめください」 | 高 |

**メッセージ例**:
- 「韓国人ゲストの問い合わせが月○○件。受け皿が足りていません」
- 「登録ホスト様の平均、初予約まで○日」
- 「まず3ヶ月無料でお試し。効果がなければそのままおやめください」

---

### 2.2 ボトルネック②: 「知らないOTA、トラブルになるのでは？」

**核心**: **信頼**と**リスクゼロ化**を同時に伝える。

| 戦略 | 内容 | 優先度 |
|------|------|--------|
| **運営者の顔・実名** | X(Twitter)個人アカウント、LINE相談など「実在の人間」が対応 | 高 |
| **ホスト優先ポリシーの明示** | 「一方的な返金は行いません」など既存LP文言の強化 | 高 |
| **退会・停止の自由** | 「いつでも掲載停止・退会可能」 | 高 |
| **契約書・約款の要約** | 複雑な約款の代わりに「ホストを守る3つの原則」など1ページ要約 | 中 |
| **既存ホストの紹介** | 「○○管理会社様ご紹介」など実名・実在の関係を公開 | 高 |
| **小規模トライアル提案** | 「1物件だけまず掲載」 | 高 |

**メッセージ例**:
- 「マイクロOTAだから、顔の見える運営。トラブル時もホスト様の味方です」
- 「掲載停止はいつでも可能。リスクゼロでお試しください」

---

### 2.3 ボトルネック③: 「登録・運営が複雑では？」

**核心**: **面倒をなくし**、**最初の一歩のハードル**を下げる。

| 戦略 | 内容 | 優先度 |
|------|------|--------|
| **LINEファーストフロー** | 「登録はLINE相談から」→ 情報収集後 **運営側が代行入力** オプション | 最優先 |
| **段階的登録** | 最小情報（写真・料金・場所）だけでまず掲載 → 後から詳細入力 | 高 |
| **代行入力サービス** | 「Airbnbの掲載情報を送っていただければ、こちらで転記します」 | 高 |
| **動画・スクショガイド** | 「5分でできる掲載の流れ」 | 中 |
| **相談時の所要時間明示** | 「初回相談は15分程度」 | 中 |

**メッセージ例**:
- 「Airbnbの掲載情報を送っていただければ、こちらのスタッフが転記します」
- 「LINEで住所・写真・料金をお伝えいただくだけでOK。面倒な入力は後回し」

## 3. チャネル別 実行戦略

### 3.1 LINE（最優先）
- **役割**: 一次接点、相談・信頼構築
- **活動**:
  - 自動返信 + 可能なら **リアルタイム人間対応**
  - 「登録希望」キーワード時 → すぐ「代行入力可能」案内
  - 週1〜2回、有益情報（韓国人ゲストのトレンドなど）共有で関係維持

### 3.2 X（Twitter）
- **役割**: ブランド露出、実績・事例共有
- **活動**:
  - 「今月の予約○件」など実績トーン
  - ホストインタビュー・事例（許可取得後）
  - 韓国人ゲストのトレンド・需要情報

### 3.3 管理代行会社・不動産ネットワーク
- **役割**: B2B、一括で複数物件確保
- **活動**:
  - 1社あたり10%手数料など条件を明確に
  - 「メッセージ代行なし」で負担軽減
  - 1社契約 → 同社保有物件を一括登録

### 3.4 既存ホストの紹介
- **役割**: 口コミ、信頼の転移
- **活動**:
  - 紹介時のインセンティブ（例: 手数料1〜2%p割引を3ヶ月）
  - 「○○様のご紹介で登録」文言で新規ホストを安心させる

## 4. LP（ランディングページ）改善提案

現在の `/lp/host` 構成を維持しつつ、**ボトルネック解消**用ブロックを追加。

### 4.1 追加推奨セクション

| セクション | 配置 | 内容 |
|------------|------|------|
| **実績・証拠** | 3つの強みの上 | 「登録ホスト○名 / 月間予約○件」など（実データで随時更新） |
| **ホストの声** | 3つの強みの下 | 1〜2件の短い声（許可取得済みホスト） |
| **登録がラクな理由** | 料金の上 | 「LINEで情報いただければ代行入力」など |
| **リスクゼロ** | CTAの上 | 「いつでも掲載停止可 / 一方的返金なし」の要約 |

### 4.2 CTA強化
- 既存: 「LINEで相談する」✅ 維持
- 追加: 「**まずは無料でお試し**」文言で心理的負担を軽減

---

## 5. オファー（提案）設計

### 5.1 推奨オファー: 「3ヶ月お試し」

- **内容**: 初回3ヶ月 手数料無料または半額（例: 10%→5%）
- **条件**: 1物件のみ、または新規登録に限る
- **効果**: 「やってみても損しない」→ 初回登録ハードルを大幅に下げる

### 5.2 代替案: 「代行登録サービス」

- **内容**: Airbnb等の既存掲載情報を送っていただければ、運営側がOTAへ代行入力
- **条件**: LINE相談時に申し込み
- **効果**: 「面倒」を排除 → 登録完了率アップ

## 9. 次のアクション

1. **即時**: LPに「実績・登録ラク・リスクゼロ」3ブロック追加（数値は利用可能データで）
2. **1週間以内**: 「3ヶ月お試し」または「代行登録」オファーのいずれか1つを確定・LP反映
3. **2週間以内**: LINE相談時に「代行入力可能」案内スクリプトを適用
4. **1ヶ月以内**: ホスト1名以上の事例を確保 → LP・Xで公開

この戦略に沿って段階的に実行すれば、ホストの心理的ハードルを下げ、登録転換率を高められます。
