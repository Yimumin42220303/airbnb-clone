# 도쿄민박 CS 응대 1장 (내부용)

사이트(`/trust`, 결제 직전 안내) 문구와 **동일한 톤**으로 응대합니다.

## 핵심 약속 (고객에게 말할 때)

> 도쿄민박은 예약 전 문의부터 체크인 안내, 숙박 중 문제 접수, 환불·민원 접수까지 한국어로 직접 대응합니다. 문제가 생기면 숙소 운영자·현지 파트너와 함께 확인하고 조정해드립니다.

**하지 말 것:** 전액 보상 보장, 무조건 환불, 법적 책임 전가 없는 단정.

## 1차 응답 목표 (내부 SLA 초안)

| 상황 | 1차 응답 | 해결 목표 |
|------|----------|-----------|
| 예약 전 문의 | 1시간 이내 | 당일 |
| 체크인 문의 | 30분 이내 | 즉시 |
| 입실 불가 | 15분 이내 | 1시간 내 대안 제시 |
| 청결/설비 | 30분 이내 | 당일 조치 요청 |
| 환불/민원 | 24시간 이내 | 사안별 기준 안내 |

```
어떤 점이 궁금하신가요? (예약 번호·체크인 날짜·숙소명을 알려주시면 더 빠르게 도와드릴 수 있습니다.)
```

## 환불·민원 1차 안내 (내부 기준)

| 케이스 | 대응 |
|--------|------|
| 단순 변심 | 숙소별 취소정책·환불 일정 안내 (`/agreement` 제5조, 사이트 환불 일정) |
| 체크인 불가 | 즉시 숙소·현지 확인 → 대체 숙소/환불 검토 |
| 정보 중대 불일치 | 증빙 확인 후 부분환불·대안 검토 |
| 청결/설비 | 사진 확인 → 청소·수리 요청, 영향도에 따라 조정 검토 |

## 에스컬레이션

- 현지 파트너·숙소 운영자 연락 불가 30분 초과 → 운영 담당자
- 법적 민원·언론·대량 환불 요청 → 대표·법률 검토 (`docs/약관-법률검토-체크리스트.md`)
