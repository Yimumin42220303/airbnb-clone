# 구글 서치콘솔 등록 후 남은 작업

tokyominbak.net 프로퍼티 등록이 완료된 뒤 진행할 작업 목록입니다.

---

## 1. 사이트맵 제출 (필수)

1. **Google Search Console** → 왼쪽 메뉴 **색인 생성(Indexing)** → **사이트맵(Sitemaps)** 이동
2. **「새 사이트맵 추가」** 에서 아래 URL 입력 후 **제출** 클릭  
   ```
   https://tokyominbak.net/sitemap.xml
   ```
3. 상태가 **「성공」** 으로 바뀔 때까지 며칠 걸릴 수 있음. 오류가 나오면 [2. 사이트맵 확인]으로 점검

---

## 2. 사이트맵 확인 (제출 전/오류 시)

- 브라우저에서 **https://tokyominbak.net/sitemap.xml** 접속
- XML이 정상적으로 보이고, 홈·검색·블로그·숙소(listing)·블로그 글 URL이 포함되어 있는지 확인
- 404나 빈 페이지면 배포·환경변수(NEXT_PUBLIC_APP_URL) 확인

---

## 3. URL 검사로 중요 페이지 색인 요청 (선택, 권장)

1. Search Console 왼쪽 **URL 검사** 선택
2. 아래 URL을 하나씩 입력 후 **색인 생성 요청** (가능한 경우)
   - `https://tokyominbak.net`
   - `https://tokyominbak.net/search`
   - `https://tokyominbak.net/blog`
   - 대표 숙소 1~2개, 대표 블로그 글 1~2개
- 새 사이트는 수일~수주 걸려 색인될 수 있음

---

## 4. robots.txt 확인

- 브라우저에서 **https://tokyominbak.net/robots.txt** 접속
- `Sitemap: https://tokyominbak.net/sitemap.xml` 이 포함되어 있고, `Allow: /` 등이 보이면 정상

---

## 5. 소유권/설정 재확인 (선택)

- **설정** → **사용자 및 권한**: 필요 시 팀원 추가
- **설정** → **속성**: 도메인(tokyominbak.net)이 올바르게 등록되었는지 확인

---

## 6. 이후 정기 확인

| 항목 | 위치 | 참고 |
|------|------|------|
| 색인 생성 페이지 수 | 색인 생성 → 페이지 | 수가 0이면 사이트맵·URL 검사 재확인 |
| 검색 노출·클릭 | 성과 → 검색결과 | 키워드·노출수·CTR 확인 |
| 오류·제외 | 색인 생성 → 페이지 | 「오류」「유효하지 않음」 등 처리 필요 여부 확인 |
| 모바일 사용 편의성 | 경험 → 페이지 경험 | 오류 있으면 수정 |

---

## 체크리스트 요약

- [ ] **사이트맵 제출**: `https://tokyominbak.net/sitemap.xml` 제출
- [ ] **사이트맵 동작 확인**: 브라우저에서 sitemap.xml 접속해 XML·URL 목록 확인
- [ ] **robots.txt 확인**: robots.txt에 Sitemap URL 포함 여부 확인
- [ ] **URL 검사**: 홈·검색·블로그 등 중요 URL 색인 생성 요청
- [ ] **며칠 후**: 색인 생성 → 페이지에서 「검색에 등록된 페이지」 수 확인
